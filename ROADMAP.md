# Roadmap

## Reliable beta — current

- Complete private single-player and hosted multiplayer acceptance testing.
- Verify Core-only ship operation and station hardware requirements.
- Verify save/reload, late join, reconnect, split/merge, backup Core failover, and power-allocation transitions.
- Verify Shield Health HUD, Console controls, and LCD Status, Compact, Combat, and Off modes.
- Verify safe Keen-native behavior with WeaponCore absent, available, and incompatible.

## 1.0 release certification

- Dedicated-server performance and stress tests.
- Accessibility, localization-ready text, installation, administrator, and troubleshooting documentation.
- Provenance audit for every shipped asset.
- Reproducible authorized release package from a tagged private build.

Public source and release material will only be published when authorized by TROAINC.
