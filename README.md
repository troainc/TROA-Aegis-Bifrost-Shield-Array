# TROA Aegis Bifrost Shield Array

An original Nordic sci-fi shield system for Space Engineers, by TROAINC.

## Project status

The project is in private reliable-beta acceptance testing. Public documentation is available here; source code, mod packages, production art, audio sessions, test worlds, and release staging remain private until an authorized release.

## Gameplay at a glance

- Aegis Core projects a seven-bank construct shield.
- Stations require an Aegis Core, Capacitor Rune, and Flux Weave; ships require one Core.
- A second Core is a hot backup rather than extra duplicated capacity.
- Bifrost Console provides field, profile, power, directional, HUD, LCD, and compatibility controls.
- Supports Keen-native protection with a safe optional WeaponCore bridge.
