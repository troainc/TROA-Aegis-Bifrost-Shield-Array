# Aegis public documentation

This repository documents a private Alpha candidate; the Workshop pages are the source of truth for what players can install today. Check the Workshop descriptions for exact dependencies, game compatibility, and installation order before subscribing.

- Start at the [README](../README.md) for the two Workshop components and their ownership: Bifrost Shield Array is authoritative; Visual Framework renders client-side telemetry/effects.
- Read the README sections on [hardware](../README.md#shield-system), [Core settings and field policy](../README.md#core-settings-and-field-policy), [power and damage compatibility](../README.md#power-damage-and-weapon-compatibility), [ship/station services](../README.md#ship-and-station-services), and [LCD/HUD](../README.md#hud-effects-and-lcds).
- Check [current validation and known limits](../README.md#current-validation-and-known-limits) before relying on candidate behavior.
- Use the [Workshop pages](https://steamcommunity.com/sharedfiles/filedetails/?id=3804076590) for player installation and current released compatibility. The public GitHub repository is documentation only; it does not provide an installable candidate package.

Do not treat HUD appearance as proof that the server-side shield or service is online. Confirm operating state in the Core/Console and validate gameplay in a controlled world.
