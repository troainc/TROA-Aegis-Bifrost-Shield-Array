# Security and release policy

## Private material

Do not submit, publish, mirror, redistribute, extract, or request:

- Private source code or development builds.
- Unreleased mod packages, models, textures, icons, sounds, or animation files.
- Test worlds, telemetry, server configurations, logs containing private data, or internal documentation.
- Copied third-party mod code or copyrighted franchise materials.

## Reporting concerns

Report security, exploit, save-corruption, multiplayer desynchronization, or compatibility concerns privately through TROAINC’s authorized channels. Include a minimal reproduction and relevant version information where possible.

Do not post exploit steps, private materials, access tokens, personal information, or unredacted private logs in public spaces.

## Release integrity

Only TROAINC-authorized releases announced through official channels are supported. Third-party packages, reuploads, extracted assets, leaked builds, and unofficial mirrors are not authorized releases and may be unsafe, incomplete, or incompatible.
